# Task 1: Data Visualization

## Objective
Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable.

## Dataset
File: `task1_dataset.csv`  
Columns:
- ID
- Name
- Age (continuous variable)
- Gender (categorical variable)
- City (categorical variable)

## Steps
1. Upload dataset into Google Colab.
2. Read dataset using Pandas.
3. Plot histogram for Age distribution.
4. Plot bar chart for Gender distribution.
5. Plot bar chart for City distribution.

## Outputs
- Age Distribution Histogram
- Gender Distribution Bar Chart
- City Distribution Bar Chart

## Tools Used
- Python (Pandas, Matplotlib)
- Google Colab
